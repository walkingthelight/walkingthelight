# Carlos's GitHub

## Personal Archaeology

Collecting and cataloguing ideas, fiction and vlogs from years of scattered writing, and building them into a searchable archive.

- [personal-archaeology](https://github.com/walkingthelight/personal-archaeology): the extraction, cataloguing and curation pipeline

## Sheet Music Projects

- [pdf-to-musescore](https://github.com/walkingthelight/pdf-to-musescore): turn PDF lead sheets into corrected MuseScore files
- [clean-the-play](https://github.com/walkingthelight/clean-the-play): transcribe live MIDI performances against a melody score
- [sheet-music-inventory](https://github.com/walkingthelight/sheet-music-inventory): a table-of-contents database for a sheet-music PDF library

## Music Projects

- [makemusic](https://github.com/walkingthelight/makemusic): isolate vocals from songs to feed melody transcription
